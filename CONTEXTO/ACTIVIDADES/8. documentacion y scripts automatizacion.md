# Actividad 8: Documentación Técnica (README.md) y Scripts de Automatización

## 1. Descripción y Objetivo
Elaborar la documentación técnica principal (`README.md`) y los scripts de automatización de despliegue (`deploy.sh`/`deploy.ps1`) y limpieza (`destroy.sh`/`destroy.ps1`), garantizando que cualquier desarrollador o docente pueda poner en marcha el ecosistema completo en menos de 15 minutos.

---

## 2. Estructura y Contenido Requerido para el `README.md`

El archivo `README.md` en la raíz del proyecto debe estructurarse con las siguientes secciones obligatorias:

1. **Diagrama de Arquitectura de Ecosistema:**
   - Diagrama descriptivo (usando sintaxis Mermaid o imagen) que ilustre:
     - Tráfico de red de entrada vía **Ingress Controller** (`conjunta3p.espe.edu.ec`).
     - Enrutamiento a los Pods de Backend, Audit Microservice y Dashboard SSE.
     - Intercambio de mensajes asíncrono vía **RabbitMQ** (`audit.events`).
     - Persistencia en bases de datos con **PVCs**.

2. **Requisitos Previos:**
   - Lista de herramientas necesarias: `Docker`, `Minikube` o `Kind`, `kubectl`.

3. **Guía de Despliegue en 15 Minutos (Paso a Paso):**
   - Comando para iniciar el clúster.
   - Construcción/carga de imágenes Docker.
   - Ejecución del despliegue: `kubectl apply -f k8s/`.
   - Instrucciones exactas para modificar `/etc/hosts` (Linux/macOS) o `drivers/etc/hosts` (Windows).

4. **Variables de Entorno y Manejo de Secretos:**
   - Explicación de ConfigMaps y Secrets utilizados y cómo se inyectan en los Pods.

5. **Instrucciones de Verificación y Escalabilidad:**
   - Comandos para escalar la auditoría (`kubectl scale deployment audit-deployment --replicas=2`).
   - Verificación de logs y health checks (`kubectl logs`, `kubectl get pods`).

## 3. Scripts de Automatización

### 3.1. Script de Despliegue Automático (`deploy.sh` / `deploy.ps1`)
Script Bash/PowerShell para automatizar todo el proceso con un solo ejecutable:

```bash
#!/usr/bin/env bash
set -e

echo "=== 1. Iniciando Clúster Minikube ==="
minikube start --driver=docker
minikube addons enable ingress

echo "=== 2. Configurando Entorno Docker de Minikube ==="
eval $(minikube -u docker-env)

echo "=== 3. Construyendo Imágenes Docker ==="
docker build -t cavalocal-backend:latest ./backend
docker build -t cavalocal-audit:latest ./audit-service
docker build -t cavalocal-dashboard:latest ./web

echo "=== 4. Aplicando Manifiestos de Kubernetes ==="
kubectl apply -f k8s/

echo "=== 5. Esperando que los Pods estén listos ==="
kubectl wait --for=condition=ready pod --all --timeout=180s

echo "=== Despliegue Completado Exitosamente ==="
echo "Asegúrese de asociar en /etc/hosts la IP '$(minikube ip)' con 'conjunta3p.espe.edu.ec'"
```

### 3.2. Script de Destrucción/Limpieza (`destroy.sh` / `destroy.ps1`)

```bash
#!/usr/bin/env bash
echo "=== Eliminando Recursos de Kubernetes ==="
kubectl delete -f k8s/ --ignore-not-found=true

echo "=== Limpieza Completada ==="
```
